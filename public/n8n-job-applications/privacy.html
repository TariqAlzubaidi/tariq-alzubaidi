Privacy policy

This application is operated for the owner's personal use. Google authorization is used to verify the owner's account; inspect Gmail Sent search results for duplicate prevention; create drafts; send owner-authorized applications and reports; and maintain an application tracker in Google Sheets. Drive access is authorized, but the present workflow uses only account metadata; the approved resume is read from a pinned local PDF.

OAuth tokens and API credentials are stored by the local n8n credential system in encrypted form. Application records and public-source evidence are retained locally, and application outcomes and unsubmitted website leads are stored in the owner's Google Sheets until the owner deletes them. n8n execution history is subject to the instance's retention and pruning settings. The owner can stop the workflow and revoke Google access through their Google Account security settings at any time; revocation stops future access but does not automatically erase previously retained records.

The approved resume text and public vacancy descriptions are sent to Google's Gemini API to match and tailor applications. Gmail mailbox contents are not sent to Gemini by this workflow. Tavily receives public job-search queries only. The approved resume PDF, portfolio link and tailored message are disclosed to an employer only when an application satisfies the configured checks and sending is authorized. Application data is not sold, used for advertising, or made available as a public dataset. Google user data is used only for the owner's requested functionality and in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

If hosted on GitHub Pages, the public information pages are delivered through GitHub's hosting infrastructure, which may process ordinary web access logs under GitHub's privacy policy. These information pages include no application login, resume download, tracking script or analytics code. Privacy inquiries: ta.alzubaidi@gmail.com.
